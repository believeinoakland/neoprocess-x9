What the product is for, whom it serves and what it must do; every module requirement cites a section here (P5). Written at onboarding (ONBOARDING §2, step 1) by the neoProcess lane, the throwaway's owner, for the dry run of the new path (`lane-neoprocess/DRYRUN.md` §4, §6).

## Vision

A throwaway product that proves the onboarding of a new project: one module that greets by name. It is never released.

## Audiences

- The neoProcess lane, which runs the dry run and reads what the tool wrote.

## Initial requirements

1. `greet(name)` returns `Hello, <name>!` for a non-empty string.
2. `greet` refuses anything that is not a non-empty string with a `TypeError`.
